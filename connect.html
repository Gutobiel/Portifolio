08 / Pronto para Agentes · MCP

Este site fala MCP.

Pronto para agentes, bem-vindo a humanos. Adicione este portfólio como conector no seu cliente de IA para que seu agente possa avaliar meus projetos, checar disponibilidade e agendar uma reunião de briefing. Sem necessidade de conta, autenticação ou cadastro.

Endpoint MCP https://gutobiel.vercel.app/api/mcp
01

Claude

  1. Abra as configurações do Claude → Connectors → Add custom connector.
  2. Defina o nome como gutobiel e cole a URL:
    https://gutobiel.vercel.app/api/mcp
  3. Conecte. Em seguida pergunte: o que o Augusto já desenvolveu?
02

ChatGPT

  1. Configurações → Apps & Connectors → Developer mode → Create.
  2. Cole a URL do endpoint e salve:
    https://gutobiel.vercel.app/api/mcp
  3. Peça ao ChatGPT para executar get_resume ou book_intro.
03

Kimi

  1. Adicione um servidor streamable-HTTP ou cole a URL nas configurações MCP do Kimi:
    https://gutobiel.vercel.app/api/mcp
  2. Execute tools/list para listar as quatro ferramentas prontas.
04

Cursor / Qualquer cliente MCP

  1. Adicione como servidor MCP streamable-HTTP nas configurações de MCP:
    https://gutobiel.vercel.app/api/mcp
  2. Execute tools/list para carregar as quatro ferramentas.
As quatro ferramentas
  • get_resume currículo técnico completo: experiência profissional, competências e links
  • get_projects projetos em destaque: Psiquê, Marca-AI, DNIT, Prompt Manager
  • check_availability status atual de agenda e disponibilidade para novos contratos
  • book_intro envia uma proposta ou briefing diretamente para a minha caixa de entrada

Prefere HTTP puro? GET /resume.json retorna o currículo em formato JSON estruturado, POST /api/hire recebe o briefing diretamente. Usuários de terminal: curl -s https://gutobiel.vercel.app/llms.txt.

Experimente perguntar ao seu agente

AGENTS.md · Contratação Direta via Agente de IA

Se o seu agente não suportar handshake MCP nativo, ele pode enviar briefings ou propostas diretamente através da API pública HTTP POST: 

curl -X POST https://gutobiel.vercel.app/api/hire \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Nome do Cliente ou Recrutador",
    "contact": "cliente@email.com",
    "brief": "Gostaríamos de conversar sobre um projeto com Agentes de IA.",
    "agent": "claude-3-7 / gpt-4o / cursor"
  }'
