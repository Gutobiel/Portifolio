08 / Agent-ready · MCP

This site speaks MCP.

Agent-ready, humans welcome. Add this portfolio as a connector and your agent can evaluate my work, check availability, and book a project intro. No account, auth, or signup.

MCP endpoint https://gutobiel.vercel.app/api/mcp
01

Claude

  1. Open Claude settings → Connectors → Add custom connector.
  2. Name it gutobiel and paste the URL:
    https://gutobiel.vercel.app/api/mcp
  3. Connect. Then ask: what has Augusto shipped?
02

ChatGPT

  1. Settings → Apps & Connectors → developer mode → Create.
  2. Paste the URL and save:
    https://gutobiel.vercel.app/api/mcp
  3. Ask ChatGPT to call get_resume or book_intro.
03

Kimi

  1. Add a streamable-HTTP MCP server, or paste the URL in Kimi's MCP settings:
    https://gutobiel.vercel.app/api/mcp
  2. Run tools/list to see the four tools.
04

Cursor / any MCP client

  1. Add a streamable-HTTP MCP server:
    https://gutobiel.vercel.app/api/mcp
  2. Run tools/list to see the four tools.
The four tools
  • get_resume full resume: experience, skills, proof points, links
  • get_projects the flagship projects: Psiquê, Marca-AI, DNIT, Prompt Manager
  • check_availability current engagement status & hiring availability
  • book_intro posts a project brief directly to my inbox

Prefer plain HTTP? GET /resume.json returns the machine-readable CV, POST /api/hire takes a brief. Terminal people: curl -s https://gutobiel.vercel.app/llms.txt.

Perguntas & Respostas (FAQ)

Quem é Augusto Gabriel (Gutobiel)?

Augusto Gabriel é um Desenvolvedor Fullstack e Engenheiro de Agentes de IA sediado em Brasília, DF. Possui sólida experiência no desenvolvimento de aplicações web corporativas e escaláveis, APIs RESTful de alto desempenho, microsserviços e integração de inteligência artificial com Python, Django, Java, Spring Boot, React e Next.js.

Qual a experiência com Agentes de IA, LangGraph e RAG?

Augusto desenvolve soluções avançadas de IA utilizando LangChain e LangGraph para orquestração de agentes autônomos stateful com múltiplos passos e ciclos. É especialista em Retrieval-Augmented Generation (RAG) para conectar LLMs (OpenAI, Anthropic, Gemini) a bases de conhecimento corporativas e bancos vetoriais, viabilizando diagnósticos automatizados e análise de dados complexos.

Como agentes de IA podem interagir com este portfólio via MCP?

O portfólio expõe um servidor Model Context Protocol (MCP) nativo no endpoint https://gutobiel.vercel.app/api/mcp compatível com JSON-RPC 2.0 via POST. Agentes como Claude Desktop e Cursor podem consultar currículo estruturado (get_resume), listar projetos (get_projects), verificar disponibilidade (check_availability) e registrar propostas diretamente (book_intro).

Como contratar ou solicitar um orçamento de projeto?

Você pode entrar em contato diretamente pelo WhatsApp (+55 61 3199-1656), por e-mail (develop.ags@gmail.com) ou através da API pública de contratação via requisição HTTP POST para https://gutobiel.vercel.app/api/hire com nome, contato e briefing do projeto.
